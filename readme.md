## Description

**specialCharacter** is an NVDA add-on that helps users quickly type **26 commonly used special characters** in documents such as Microsoft Word, Excel, official reports, and data tables — without needing to remember Alt codes or search through the Symbol menu.

Perfect for anyone who frequently works with official documents, reports, academic papers, or data entry.

### Examples of commonly used characters
– (En Dash)   — (Em Dash)   … (Ellipsis)   ©   ®   ™   ±   ×   ÷   ≠   ≤   ≥   √   ∞   ≈   °   µ   ¶   §   †   ‡   •   ✓

## 🔑 Main Hotkeys

| Shortcut                              | Function                                                                |
|---------------------------------------|-------------------------------------------------------------------------|
| `Ctrl+0` – `Ctrl+9`                   | Type special characters from Set 1 (10 default characters)              |
| `Ctrl+-` (Ctrl+Minus)                 | Type the 11th character in Set 1                                        |
| `Ctrl+=` (Ctrl+Equals)                | Type the 12th character in Set 1                                        |
| `Shift+Windows+.`                     | – (En Dash)  → Alt+0150                                                 |
| `Shift+Windows+/`                     | — (Em Dash)  → Alt+0151                                                 |
| `Shift+Backspace` (single press)      | Switch between Set 1 ↔ Set 2                                            |
| `Shift+Backspace` (double press)      | Toggle the entire add-on on/off                                         |

> **Note**: All keyboard shortcuts can be freely customized/reassigned in **NVDA → Input Gestures**.

## Customization

1. Go to **NVDA menu → Preferences → Settings...**
2. Select the **Special Characters** category
3. You can:
   - Switch between Set 1 and Set 2
   - Reorder characters
   - Modify existing characters
   - Add new special characters you frequently use

## Installation

1. Download the latest `.nvda-addon` file from [Releases](https://github.com/chaichaimee/specialCharacter/releases)
2. Double-click the downloaded `.nvda-addon` file
3. NVDA will ask for confirmation → click **Yes**
4. Restart NVDA when installation is complete

## Compatibility

- NVDA **2022.1** and later (recommended: latest version)
- Windows 10 / 11
