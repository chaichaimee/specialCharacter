Профессиональная точность в каждом символе

specialCharacter — это профессиональное дополнение для NVDA, созданное для пользователей, которым важны скорость и точность при подготовке документов. Независимо от того, работаете ли вы в Microsoft Office (Word, Excel) или используете продвинутые текстовые редакторы для программирования и работы с простым текстом, этот инструмент значительно упрощает процесс ввода.

Забудьте об утомительном процессе запоминания и ввода сложных 4-значных Alt-кодов. Это дополнение заменяет архаичные команды оптимизированными горячими клавишами, позволяя мгновенно вставлять официальные символы, технические знаки и специальную пунктуацию. Это гарантирует, что ваши отчеты и таблицы данных будут соответствовать профессиональным стандартам без нарушения ритма печати.


Особенности:

  • Высокоскоростной ввод символов: Замените традиционные последовательности Alt-кодов прямыми сочетаниями клавиш. То, что раньше требовало нескольких нажатий, теперь происходит одним нажатием.
  • Поддержка различных сред: Оптимизировано для бесперебойной работы в пакетах Microsoft Office и различных текстовых редакторах, обеспечивая единообразие на всех ваших рабочих платформах.
  • Настраиваемый рабочий процесс: Имеет два основных набора (Set 1 и Set 2), которые полностью адаптируемы. Вы можете изменять, переставлять или обновлять символы через настройки NVDA в соответствии с требованиями вашей отрасли.

Горячие клавиши:

  • Ctrl+0 до Ctrl+9, Ctrl+Минус (-) и Ctrl+Равно (=): Мгновенный вывод специальных символов из активной конфигурации.
  • Shift+Windows+. : Вставить среднее тире (–) — используется для обозначения числовых диапазонов (например, 2020–2025).
  • Shift+Windows+/ : Вставить длинное тире (—) — используется для профессиональных текстовых пауз и уточнений.
  • Shift+Backspace (одиночное нажатие): Мгновенное переключение между наборами Set 1 и Set 2.
  • Shift+Backspace (двойное нажатие): Включение или выключение функций дополнения.

** Все сочетания клавиш могут быть полностью перенастроены в меню «Жесты ввода» NVDA.


Конфигурация:

Доступ к настройкам через: Меню NVDA → Параметры → Настройки → Special Characters для управления вашими профессиональными наборами символов.
