Профессиональная точность в каждом символе

specialCharacter — это профессиональное дополнение для NVDA, созданное для тех, кому важна скорость и точность при подготовке документов. Работаете ли вы в Microsoft Office (Word, Excel) или используете продвинутые текстовые редакторы для кода, этот инструмент значительно ускорит процесс ввода.

Забудьте об изнурительном заучивании четырехзначных Alt-кодов. Это дополнение заменяет устаревшие команды удобными горячими клавишами, позволяя мгновенно вставлять официальные символы, технические знаки и специальную пунктуацию. Ваши отчеты будут соответствовать профессиональным стандартам без потери ритма печати.


Особенности:

  • Высокоскоростной ввод: Замените традиционные последовательности Alt-кодов прямыми сочетаниями клавиш. То, что раньше требовало множества нажатий, теперь делается одним касанием.
  • Универсальная поддержка: Оптимизировано для бесперебойной работы в пакете Microsoft Office и различных текстовых редакторах для обеспечения единообразия на всех платформах.
  • Настраиваемый процесс: Включает два основных набора (Set 1 и Set 2), которые можно полностью адаптировать. Изменяйте или обновляйте символы через настройки NVDA под задачи вашей отрасли.

Горячие клавиши:

  • Ctrl+0 – Ctrl+9, Ctrl+Минус (-) и Ctrl+Равно (=): Мгновенный вывод спецсимволов из активной конфигурации.
  • Shift+Windows+. : Вставка среднего тире (–) — используется для числовых диапазонов (например, 2020–2025).
  • Shift+Windows+/ : Вставка длинного тире (—) — для профессионального оформления текста.
  • Shift+Backspace (Одиночное нажатие): Мгновенное переключение между Набором 1 и Набором 2.
  • Shift+Backspace (Двойное нажатие): Включение или выключение функций дополнения.

** Все сочетания клавиш можно полностью перенастроить в меню «Жесты ввода» NVDA.


Настройка:

Доступ к параметрам: Меню NVDA → Настройки → Параметры → Special Characters для управления вашими наборами символов.
