Special Character


Escribe cualquier carácter especial, en cualquier lugar, al instante.


autor: chai chaimee

url: https://github.com/chaichaimee/SpecialCharacter


Introducción


Special Character es un complemento para NVDA que te permite insertar símbolos y caracteres especiales —como viñetas, signos de moneda, comillas o guiones— con una sola pulsación de tecla, en casi cualquier aplicación.


En lugar de buscar en el Mapa de caracteres de Windows o memorizar códigos Alt oscuros, presionas un atajo simple de Ctrl+número (o Ctrl+- / Ctrl+=) y el carácter se escribe por ti, anunciado por la voz exactamente una vez.


Hay disponibles dos conjuntos independientes de 12 caracteres, lo que te permite mantener dos colecciones diferentes (por ejemplo, símbolos cotidianos en un conjunto y menos comunes en otro) y cambiar entre ellos al instante. El complemento también se puede personalizar por completo a través de su propio panel en el diálogo de Configuración de NVDA, y se puede activar o desactivar sobre la marcha sin abandonar tu aplicación actual.


Atajos de teclado


Ctrl+1 a Ctrl+9, Ctrl+0, Ctrl+-, Ctrl+=
Una pulsación: Inserta el carácter almacenado en esa ranura (12 ranuras personalizables) para el conjunto activo actualmente
Shift+Windows+|
Una pulsación: Inserta una barra vertical ( | )
Shift+Windows+.
Una pulsación: Inserta un guion en ( – )
Shift+Windows+/
Una pulsación: Inserta un guion em ( — )
Shift+Retroceso (Backspace)
Una pulsación: Cambia entre el Conjunto de caracteres 1 y el Conjunto de caracteres 2
Doble pulsación (en medio segundo): Activa o desactiva el complemento Special Character

Características


1. Conjuntos de caracteres de doce ranuras (Conjunto 1 y Conjunto 2)


Cada carácter se almacena en una de las 12 ranuras, asignadas a Ctrl+1, Ctrl+2 … Ctrl+9, Ctrl+0, Ctrl+-, y Ctrl+=. Hay dos conjuntos completos de estas 12 ranuras, por lo que puedes mantener dos colecciones de símbolos diferentes y alternar entre ellas con Shift+Retroceso.


De manera predeterminada, algunas ranuras ya contienen caracteres listos para usar, por ejemplo, una viñeta (•), un par de paréntesis, el signo de baht tailandés (฿) y el signo de euro (€) en el Conjunto 1, y una comilla simple, una comilla doble y unos puntos suspensivos (…) en el Conjunto 2. Las ranuras restantes quedan libres para que las llenes con los caracteres que más uses.

2. Panel de configuración integrado


El complemento registra su propia página directamente dentro del diálogo de Configuración de NVDA (en "Special Character Settings"). Desde allí puedes:


• Elegir el Conjunto 1 o el Conjunto 2 desde un cuadro combinado.
• Escribir o editar el carácter asignado a cada una de las 12 ranuras en su propio campo de texto.
• Cambiar entre conjuntos dentro del propio panel; tus ediciones en el conjunto que estabas viendo se guardan automáticamente al cambiar.
• Pulsar Aceptar para guardar todo en el disco de una vez.

3. Lógica de inserción consciente del contexto


Cuando presionas un atajo, el complemento examina la aplicación que tiene el foco actualmente y elige la forma más segura de escribir el carácter en ella. Paso a paso, esto es lo que ocurre:


1. Lee el nombre del módulo de la aplicación enfocada.
2. Si la aplicación es Microsoft Word, primero intenta insertar el carácter directamente a través del modelo de objetos propio de Word (Selection.TypeText). Esto se comporta como la escritura real, nunca toca el portapapeles y evita la ventana emergente de "Opciones de pegado" de Word. Si esa llamada falla, recurre a copiar el carácter al portapapeles y simular Ctrl+V.
3. Si la aplicación es un navegador web (Chrome, Firefox, Brave, Edge o Safari), los caracteres que también son teclas normales del teclado —las comillas dobles, la barra diagonal, la barra diagonal inversa, el punto y la barra vertical— se envían directamente como una pulsación de tecla. Cualquier otro carácter se copia al portapapeles y se pega después de un breve retraso de 40 milisegundos, lo que da tiempo al lector del portapapeles del navegador para ver el contenido actualizado antes de que ocurra el pegado.
4. Si hay conectada una línea braille con entrada braille, el carácter se envía a través del controlador de entrada braille en su lugar.
5. Si el control enfocado expone un método directo de inserción de texto, el complemento lo utiliza.
6. Como último recurso, en cualquier otra situación, el carácter se copia al portapapeles y se pega con un breve retraso, igual que el mecanismo alternativo del navegador.


Una vez que se ha insertado el carácter, NVDA lo lee exactamente una vez.

4. Compatibilidad dual con las APIs de teclado de NVDA antiguas y nuevas


Al iniciarse, el complemento comprueba si la API de teclado más nueva winBindings.user32 está disponible (introducida en las compilaciones de 64 bits de NVDA 2026.1). Si lo está, el complemento utiliza esa API moderna para cualquier simulación de teclas de bajo nivel que necesite en Word; de lo contrario, recurre automáticamente a la API anterior winUser, por lo que los mismos atajos funcionan correctamente tanto en instalaciones de NVDA anteriores como más recientes, de 32 y 64 bits.


En ambos casos, el complemento desactiva temporalmente la opción de NVDA "anunciar caracteres escritos" mientras inserta un carácter, luego restaura tu configuración original inmediatamente después y enuncia el carácter por sí mismo, para que nunca lo escuches anunciado dos veces.

5. Conteo inteligente de pulsaciones en Shift+Retroceso


Presionar Shift+Retroceso no actúa de inmediato. En su lugar, el complemento espera medio segundo para ver si lo presionas de nuevo:


• Si solo ocurre una pulsación dentro de esa ventana de medio segundo, cambia el conjunto de caracteres activo (Conjunto 1 ↔ Conjunto 2) y anuncia qué conjunto está activo ahora.
• Si ocurre una segunda pulsación (o más) dentro de la misma ventana, en su lugar activa o desactiva todo el complemento, anunciando el nuevo estado.


Esto permite que una sola combinación de teclas fácil de recordar cubra dos acciones relacionadas sin necesidad de dos atajos separados.

6. Atajos independientes para guiones y barra


Tres caracteres que se necesitan comúnmente al escribir —la barra vertical, el guion en y el guion em— tienen sus propios atajos dedicados (Shift+Windows+|, Shift+Windows+. y Shift+Windows+/) para que no tengas que agotar una ranura numerada para ellos.

7. Configuración persistente y de migración automática


Tus conjuntos de caracteres se guardan como un archivo JSON llamado specialCharacters.json dentro de una subcarpeta ChaiChaimee de tu carpeta de configuración de usuario de NVDA, por lo que tus caracteres personalizados se conservan entre sesiones y actualizaciones de NVDA.


Si el complemento detecta un archivo de configuración sobrante de una versión anterior directamente en la carpeta de configuración principal de NVDA, copia automáticamente su contenido en la nueva ubicación de la subcarpeta y solo elimina el archivo antiguo una vez que se ha verificado la copia, para que tus personalizaciones existentes nunca se pierdan durante una actualización.

8. Activar / Desactivar sin perder la configuración


Desactivar el complemento (mediante una doble pulsación de Shift+Retroceso) simplemente hace que deje de responder a los atajos de caracteres; tus conjuntos configurados permanecen guardados y se vuelven a usar tan pronto como vuelvas a activar el complemento.


Nota: Los atajos de inserción de caracteres (Ctrl+1–0, Ctrl+-, Ctrl+=) solo están disponibles mientras el complemento está habilitado. Si no pasa nada cuando presionas uno, comprueba si el complemento se ha desactivado con una doble pulsación de Shift+Retroceso.
