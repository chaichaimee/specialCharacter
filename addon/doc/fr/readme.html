Special Character


Tapez n'importe quel caractère spécial, n'importe où, instantanément.


auteur : chai chaimee

url : https://github.com/chaichaimee/SpecialCharacter


Introduction


Special Character est un module complémentaire pour NVDA qui vous permet d'insérer des symboles et des caractères spéciaux — tels que des puces, des signes monétaires, des guillemets ou des tirets — d'une simple frappe de touche, dans presque n'importe quelle application.


Au lieu de fouiller dans la table des caractères Windows ou de mémoriser des codes Alt obscurs, vous appuyez sur un raccourci simple de type Ctrl+chiffre (ou Ctrl+- / Ctrl+=) et le caractère est tapé pour vous, annoncé par la synthèse vocale exactement une fois.


Deux jeux indépendants de 12 caractères sont disponibles, ce qui vous permet de conserver deux collections différentes (par exemple, des symboles du quotidien dans l'un et des symboles moins courants dans l'autre) et de basculer instantanément entre elles. Le module complémentaire peut également être entièrement personnalisé via son propre panneau dans la boîte de dialogue Paramètres de NVDA, et il peut être activé ou désactivé à la volée sans quitter votre application actuelle.


Raccourcis clavier


Ctrl+1 à Ctrl+9, Ctrl+0, Ctrl+-, Ctrl+=
Simple pression : Insère le caractère stocké dans cet emplacement (12 emplacements personnalisables) pour le jeu actuellement actif
Shift+Windows+|
Simple pression : Insère une barre verticale ( | )
Shift+Windows+.
Simple pression : Insère un tiret en ( – )
Shift+Windows+/
Simple pression : Insère un tiret em ( — )
Shift+Retour arrière (Backspace)
Simple pression : Bascule entre le jeu de caractères 1 et le jeu de caractères 2
Double pression (en moins d'une demi-seconde) : Active ou désactive le module complémentaire Special Character

Fonctionnalités


1. Jeux de caractères à douze emplacements (Jeu 1 et Jeu 2)


Chaque caractère est stocké dans l'un des 12 emplacements, associés à Ctrl+1, Ctrl+2 … Ctrl+9, Ctrl+0, Ctrl+-, et Ctrl+=. Il existe deux jeux complets de ces 12 emplacements, ce qui vous permet de maintenir deux collections de symboles différentes et de passer de l'une à l'autre avec Shift+Retour arrière.


Par défaut, certains emplacements contiennent déjà des caractères prêts à l'emploi, par exemple une puce (•), une paire de parenthèses, le signe bahts thaïlandais (฿) et le signe euro (€) dans le Jeu 1, ainsi qu'une apostrophe, des guillemets et des points de suspension (…) dans le Jeu 2. Les emplacements restants sont laissés à votre disposition pour y placer les caractères que vous utilisez le plus.

2. Panneau de configuration intégré


Le module complémentaire enregistre sa propre page directement dans la boîte de dialogue Paramètres de NVDA (sous "Special Character Settings"). De là, vous pouvez :


• Choisir le Jeu 1 ou le Jeu 2 dans une liste déroulante.
• Taper ou modifier le caractère assigné à chacun des 12 emplacements dans son propre champ de texte.
• Basculer entre les jeux à l'intérieur du panneau lui-même ; vos modifications sur le jeu que vous visualisiez sont conservées automatiquement lors du changement.
• Appuyer sur OK pour tout enregistrer sur le disque en une seule fois.

3. Logique d'insertion contextuelle


Lorsque vous appuyez sur un raccourci, le module examine l'application qui a actuellement le focus et choisit la manière la plus sûre d'y taper le caractère. Étape par étape, voici ce qui se passe :


1. Il lit le nom du module de l'application focalisée.
2. Si l'application est Microsoft Word, il essaie d'abord d'insérer le caractère directement via le modèle d'objet de Word (Selection.TypeText). Cela se comporte comme une vraie frappe, ne touche jamais au Presse-papiers et évite la fenêtre contextuelle "Options de collage" de Word. Si cet appel échoue, il se rabat sur la copie du caractère dans le Presse-papiers et la simulation de Ctrl+V.
3. Si l'application est un navigateur Web (Chrome, Firefox, Brave, Edge ou Safari), les caractères qui sont également des touches de clavier ordinaires — les guillemets, la barre oblique, la barre oblique inverse, le point et la barre verticale — sont envoyés directement comme une frappe de touche. Tout autre caractère est copié dans le Presse-papiers et collé après un bref délai de 40 millisecondes, ce qui laisse le temps au lecteur de presse-papiers du navigateur de voir le contenu mis à jour avant que le collage ne se produise.
4. Si un afficheur braille avec saisie braille est connecté, le caractère est envoyé via le gestionnaire de saisie braille à la place.
5. Si le contrôle focalisé expose une méthode directe d'insertion de texte, le module l'utilise.
6. En dernier recours, dans toute autre situation, le caractère est copié dans le Presse-papiers et collé avec un court délai, de la même manière que le mode de secours du navigateur.


Une fois le caractère inséré, NVDA le prononce exactement une fois.

4. Double compatibilité avec les anciennes et nouvelles API de clavier NVDA


Au démarrage, le module vérifie si la nouvelle API de clavier winBindings.user32 est disponible (introduite dans les versions 64 bits de NVDA 2026.1). Si c'est le cas, le module utilise cette API moderne pour toute simulation de touche de bas niveau nécessaire dans Word ; sinon, il revient automatiquement à l'ancienne API winUser, de sorte que les mêmes raccourcis fonctionnent correctement sur les installations de NVDA plus anciennes et plus récentes, en 32 bits et 64 bits.


Dans les deux cas, le module désactive temporairement l'option NVDA "annoncer les caractères tapés" pendant qu'il insère un caractère, puis restaure votre paramètre d'origine juste après et énonce le caractère lui-même, afin que vous ne l'entendiez jamais annoncé deux fois.

5. Comptage intelligent des pressions sur Shift+Retour arrière


Appuyer sur Shift+Retour arrière n'agit pas immédiatement. Au lieu de cela, le module attend une demi-seconde pour voir si vous appuyez à nouveau :


• Si une seule pression se produit dans cette fenêtre d'une demi-seconde, il bascule le jeu de caractères actif (Jeu 1 ↔ Jeu 2) et annonce quel jeu est désormais actif.
• Si une seconde pression (ou plus) se produit dans la même fenêtre, il active ou désactive à la place l'ensemble du module complémentaire, en annonçant le nouvel état.


Cela permet à une seule combinaison de touches facile à retenir de couvrir deux actions liées sans nécessiter deux raccourcis séparés.

6. Raccourcis indépendants pour les tirets et la barre


Trois caractères couramment nécessaires lors de la rédaction — la barre verticale, le tiret en et le tiret em — ont leurs propres raccourcis dédiés (Shift+Windows+|, Shift+Windows+. et Shift+Windows+/) afin que vous n'ayez pas à utiliser un emplacement numéroté pour eux.

7. Configuration persistante à auto-migration


Vos jeux de caractères sont enregistrés sous forme de fichier JSON nommé specialCharacters.json dans un sous-dossier ChaiChaimee de votre dossier de configuration utilisateur NVDA, de sorte que vos caractères personnalisés sont conservés entre les sessions et les mises à jour de NVDA.


Si le module détecte un fichier de configuration provenant d'une version antérieure directement dans le dossier de configuration principal de NVDA, il copie automatiquement son contenu dans le nouvel emplacement du sous-dossier et ne supprime l'ancien fichier qu'une fois la copie vérifiée, de sorte que vos personnalisations existantes ne soient jamais perdues lors d'une mise à niveau.

8. Activer / Désactiver sans perdre les paramètres


Désactiver le module complémentaire (via une double pression sur Shift+Retour arrière) arrête simplement sa réponse aux raccourcis de caractères ; vos jeux configurés restent enregistrés et sont réutilisés dès que vous réactivez le module.


Remarque : Les raccourcis d'insertion de caractères (Ctrl+1–0, Ctrl+-, Ctrl+=) ne sont disponibles que lorsque le module complémentaire est activé. Si rien ne se passe lorsque vous en pressez un, vérifiez si le module a été désactivé par une double pression de Shift+Retour arrière.
