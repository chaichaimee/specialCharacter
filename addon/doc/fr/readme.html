La précision professionnelle au bout des doigts

specialCharacter est une extension NVDA de qualité professionnelle conçue pour les utilisateurs exigeants rapidité et précision. Que vous travailliez sur Microsoft Office (Word, Excel) ou sur des éditeurs de texte avancés pour le code, cet outil optimise considérablement votre saisie.

Oubliez la mémorisation fastidieuse des codes Alt à 4 chiffres. Cette extension remplace ces commandes archaïques par des raccourcis simplifiés, vous permettant d'insérer instantanément des symboles officiels, des signes techniques et une ponctuation spécialisée. Vos rapports conservent ainsi un standard professionnel sans interrompre votre rythme de frappe.


Fonctionnalités :

  • Saisie ultra-rapide : Remplacez les séquences Alt classiques par des raccourcis directs. Ce qui nécessitait plusieurs touches se fait désormais en une seule pression.
  • Compatibilité étendue : Optimisé pour une performance fluide sur la suite Microsoft Office et divers éditeurs de texte, assurant une cohérence sur toutes vos plateformes.
  • Flux de travail personnalisable : Propose deux jeux de caractères (Set 1 et Set 2) entièrement adaptables. Modifiez ou mettez à jour vos caractères via les paramètres NVDA selon vos besoins spécifiques.

Raccourcis clavier :

  • Ctrl+0 à Ctrl+9, Ctrl+Moins (-), et Ctrl+Égal (=) : Insère instantanément les caractères de votre configuration active.
  • Maj+Windows+. : Insère un tiret moyen (–) – Idéal pour les plages numériques (ex: 2020–2025).
  • Maj+Windows+/ : Insère un tiret cadratin (—) – Utilisé pour les ruptures de texte et les précisions professionnelles.
  • Maj+Retour arrière (Simple pression) : Alterne instantanément entre le Set 1 et le Set 2.
  • Maj+Retour arrière (Double pression) : Active ou désactive l'extension.

** Tous les raccourcis peuvent être reconfigurés dans le menu "Gestes d'entrée" de NVDA.


Configuration :

Accès via : Menu NVDA → Préférences → Paramètres → Special Characters pour gérer vos jeux de caractères.
