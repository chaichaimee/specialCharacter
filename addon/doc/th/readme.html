Special Character


พิมพ์อักขระพิเศษใด ๆ ได้ทุกที่ทันที


ผู้พัฒนา: chai chaimee

เว็บไซต์: https://github.com/chaichaimee/SpecialCharacter


บทนำ


Special Character คือส่วนเสริม (Add-on) ของ NVDA ที่ช่วยให้คุณแทรกสัญลักษณ์และอักขระพิเศษต่าง ๆ เช่น สัญลักษณ์จุดหัวข้อ (Bullet), เครื่องหมายสกุลเงิน, เครื่องหมายคำพูด หรือเครื่องหมายขีดคั่น ได้ด้วยการกดปุ่มเพียงครั้งเดียวในเกือบทุกแอปพลิเคชัน


แทนที่จะต้องค้นหาจากหน้าต่าง Windows Character Map หรือจำรหัส Alt-code ที่ซับซ้อน คุณเพียงแค่กดปุ่มลัดง่าย ๆ อย่าง Ctrl+ตัวเลข (หรือ Ctrl+- / Ctrl+=) อักขระนั้นก็จะถูกพิมพ์ลงไปให้คุณทันที พร้อมทั้งมีเสียงพูดอ่านอักขระนั้นขึ้นมาเพียงครั้งเดียว


มีชุดอักขระอิสระให้ใช้งานถึง 2 ชุด ชุดละ 12 ช่อง ทำให้คุณสามารถเก็บคอลเลกชันสัญลักษณ์ที่แตกต่างกันได้สองชุด (เช่น สัญลักษณ์ที่ใช้ประจำในชุดหนึ่ง และสัญลักษณ์ที่ใช้น้อยกว่าในอีกชุดหนึ่ง) และสลับใช้งานระหว่างชุดได้อย่างรวดเร็ว นอกจากนี้ ส่วนเสริมยังสามารถปรับแต่งได้อย่างเต็มที่ผ่านหน้าต่างตั้งค่าของ NVDA เอง และสามารถเปิดหรือปิดการใช้งานได้ทันทีโดยไม่ต้องออกจากแอปพลิเคชันที่คุณใช้งานอยู่


ปุ่มลัด (Hot Keys)


Ctrl+1 ถึง Ctrl+9, Ctrl+0, Ctrl+-, Ctrl+=
กดครั้งเดียว: แทรกอักขระที่บันทึกไว้ในช่องนั้น (มี 12 ช่องที่ปรับแต่งได้) สำหรับชุดอักขระที่ใช้งานอยู่ปัจจุบัน
Shift+Windows+|
กดครั้งเดียว: แทรกเครื่องหมายเส้นตั้งตรง ( | )
Shift+Windows+.
กดครั้งเดียว: แทรกเครื่องหมาย en dash ( – )
Shift+Windows+/
กดครั้งเดียว: แทรกเครื่องหมาย em dash ( — )
Shift+Backspace
กดครั้งเดียว: สลับระหว่างชุดอักขระ 1 และชุดอักขระ 2
กดสองครั้งติดกัน (ภายในครึ่งวินาที): เปิดหรือปิดการทำงานของส่วนเสริม Special Character

คุณสมบัติ


1. ชุดอักขระ 12 ช่อง (ชุดที่ 1 และชุดที่ 2)


อักขระแต่ละตัวจะถูกจัดเก็บไว้ในช่องใดช่องหนึ่งจากทั้งหมด 12 ช่อง ซึ่งผูกไว้กับปุ่ม Ctrl+1, Ctrl+2 … Ctrl+9, Ctrl+0, Ctrl+- และ Ctrl+= โดยจะมีชุดอักขระ 12 ช่องนี้ให้ครบทั้ง 2 ชุด คุณจึงสามารถจัดการคอลเลกชันสัญลักษณ์ที่ต่างกันสองชุดและสลับไปมาระหว่างกันได้ด้วยปุ่ม Shift+Backspace


ค่าเริ่มต้นในบางช่องจะมีอักขระที่พร้อมใช้งานอยู่แล้ว เช่น สัญลักษณ์จุดหัวข้อ (•), เครื่องหมายวงเล็บ, เครื่องหมายบาทไทย (฿) และเครื่องหมายยูโร (€) ในชุดที่ 1 รวมถึงเครื่องหมายคำพูดเดี่ยว เครื่องหมายคำพูดคู่ และจุดไข่ปลา (…) ในชุดที่ 2 ส่วนช่องที่เหลือเปิดว่างไว้ให้คุณเติมอักขระที่คุณใช้งานบ่อยที่สุดด้วยตนเอง

2. แผงตั้งค่าในตัว


ส่วนเสริมนี้จะเพิ่มหน้าการตั้งค่าของตนเองเข้าไปในหน้าต่างการตั้งค่าของ NVDA โดยตรง (ภายใต้หัวข้อ "Special Character Settings") ซึ่งจากตรงนี้คุณสามารถ:


• เลือกชุดที่ 1 หรือชุดที่ 2 ได้จากกล่องคอมโบ
• พิมพ์หรือแก้ไขอักขระที่กำหนดให้กับแต่ละช่องทั้ง 12 ช่องได้ในช่องป้อนข้อความของตนเอง
• สลับระหว่างชุดอักขระได้ภายในแผงตั้งค่าโดยตรง การแก้ไขใด ๆ ในชุดที่คุณกำลังดูอยู่จะถูกบันทึกไว้โดยอัตโนมัติเมื่อทำการสลับชุด
• กดปุ่ม OK เพื่อบันทึกทุกอย่างลงในดิสก์ทีเดียวจบ

3. ตรรกะการแทรกข้อความตามบริบท


เมื่อคุณกดปุ่มลัด ส่วนเสริมจะตรวจสอบว่าแอปพลิเคชันใดกำลังโฟกัสอยู่ และเลือกวิธีที่ปลอดภัยที่สุดในการพิมพ์อักขระลงไป โดยมีขั้นตอนดังนี้:


1. อ่านชื่อโมดูลของแอปพลิเคชันที่กำลังโฟกัส
2. หากแอปพลิเคชันนั้นคือ Microsoft Word ส่วนเสริมจะพยายามแทรกอักขระผ่านโมเดลออบเจ็กต์ของ Word โดยตรง (Selection.TypeText) ซึ่งจะมีพฤติกรรมเหมือนการพิมพ์จริง ไม่แตะต้องคลิปบอร์ด และหลีกเลี่ยงหน้าต่างป๊อปอัป "ตัวเลือกการวาง" ของ Word หากวิธีนี้ไม่สำเร็จ ระบบจะสำรองโดยการคัดลอกอักขระไปยังคลิปบอร์ดแล้วจำลองการกด Ctrl+V แทน
3. หากแอปพลิเคชันเป็นเว็บเบราว์เซอร์ (Chrome, Firefox, Brave, Edge หรือ Safari) อักขระที่เป็นปุ่มคีย์บอร์ดทั่วไปอยู่แล้ว — เช่น เครื่องหมายคำพูดคู่, สแลช, แบ็กลแลช, จุด และเส้นตั้งตรง — จะถูกส่งเป็นแป้นพิมพ์กดโดยตรง ส่วนอักขระอื่น ๆ จะถูกคัดลอกไปยังคลิปบอร์ดและวางหลังจากหน่วงเวลาสั้น ๆ 40 มิลลิวินาที ซึ่งช่วยให้โปรแกรมอ่านคลิปบอร์ดของเบราว์เซอร์ตรวจจับเนื้อหาที่อัปเดตทันก่อนที่จะทำการวาง
4. หากมีการเชื่อมต่อจอแสดงผลอักษรเบรลล์ที่มีการป้อนข้อมูลด้วยอักษรเบรลล์ อักขระจะถูกส่งผ่านตัวจัดการการป้อนข้อมูลอักษรเบรลล์แทน
5. หากคอนโทรลที่โฟกัสอยู่มีเมธอดสำหรับการแทรกข้อความโดยตรง ส่วนเสริมจะใช้งานเมธอดนั้น
6. ในกรณีสุดท้ายสำหรับสถานการณ์อื่น ๆ อักขระจะถูกคัดลอกไปยังคลิปบอร์ดและวางพร้อมหน่วงเวลาสั้น ๆ เช่นเดียวกับกรณีสำรองของเว็บเบราว์เซอร์


หลังจากที่แทรกอักขระเรียบร้อยแล้ว NVDA จะอ่านออกเสียงอักขระนั้นให้ฟังเพียงครั้งเดียว

4. รองรับทั้ง API แป้นพิมพ์ NVDA รุ่นเก่าและรุ่นใหม่


เมื่อเริ่มต้นทำงาน ส่วนเสริมจะตรวจสอบว่ามี API แป้นพิมพ์รุ่นใหม่กว่าอย่าง winBindings.user32 ให้ใช้งานหรือไม่ (ซึ่งเริ่มมีใน NVDA 2026.1 รุ่น 64 บิต) หากมี ส่วนเสริมจะใช้ API สมัยใหม่นี้สำหรับการจำลองปุ่มระดับต่ำที่จำเป็นใน Word แต่ถ้าไม่มี ระบบจะสำรองไปใช้ API winUser แบบเก่าโดยอัตโนมัติ ทำให้ปุ่มลัดชุดเดียวกันนี้ทำงานได้อย่างถูกต้องทั้งบน NVDA เวอร์ชันเก่าและใหม่ รวมถึงทั้งแบบ 32 บิตและ 64 บิต


ไม่ว่ากรณีใด ส่วนเสริมจะปิดการใช้งานตัวเลือก "พูดอักขระที่พิมพ์" ของ NVDA ชั่วคราวในขณะที่ทำการแทรกอักขระ จากนั้นจะคืนค่าการตั้งค่าเดิมของคุณทันทีและทำหน้าที่อ่านออกเสียงอักขระนั้นด้วยตนเอง คุณจึงมั่นใจได้ว่าจะไม่ได้ยินเสียงอ่านซ้ำสองครั้ง

5. การนับจำนวนครั้งที่กดปุ่ม Shift+Backspace อย่างชาญฉลาด


การกดปุ่ม Shift+Backspace จะยังไม่ทำงานทันที แต่ส่วนเสริมจะรอเวลาครึ่งวินาทีเพื่อดูว่าคุณจะกดซ้ำอีกครั้งหรือไม่:


• หากมีการกดเพียงครั้งเดียวภายในช่วงเวลานصفวินาทีนั้น ระบบจะทำการสลับชุดอักขระที่ใช้งาน (ชุด 1 ↔ ชุด 2) และประกาศให้ทราบว่าขณะนี้ใช้งานชุดใดอยู่
• หากมีการกดครั้งที่สอง (หรือมากกว่า) ภายในช่วงเวลาเดียวกัน ระบบจะสลับเป็นการเปิดหรือปิดการทำงานของส่วนเสริมทั้งหมดแทน พร้อมทั้งประกาศสถานะใหม่ให้ทราบ


วิธีนี้ช่วยให้การใช้ชุดปุ่มลัดเพียงชุดเดียวที่จำง่าย สามารถครอบคลุมการทำงานที่เกี่ยวข้องกันได้ถึงสองอย่างโดยไม่ต้องใช้ปุ่มลัดแยกกันให้ยุ่งยาก

6. ปุ่มลัดแยกต่างหากสำหรับเครื่องหมายขีดคั่นและเส้นตั้ง


อักขระสามตัวที่มักใช้งานบ่อยในการเขียน — เส้นตั้งตรง, en dash และ em dash — มีปุ่มลัดเฉพาะตัว (Shift+Windows+|, Shift+Windows+. และ Shift+Windows+/) ทำให้คุณไม่ต้องเสียช่องอักขระที่มีหมายเลขไปกับสัญลักษณ์เหล่านี้

7. การบันทึกค่าและการย้ายไฟล์ตั้งค่าอัตโนมัติ


ชุดอักขระของคุณจะถูกบันทึกเป็นไฟล์ JSON ในชื่อ specialCharacters.json ภายในโฟลเดอร์ย่อย ChaiChaimee ของโฟลเดอร์การตั้งค่าผู้ใช้ NVDA ทำให้การตั้งค่าอักขระของคุณยังคงอยู่ครบถ้วนแม้จะปิดเปิดโปรแกรมใหม่หรืออัปเดต NVDA


หากส่วนเสริมตรวจพบไฟล์ตั้งค่าค้างจากเวอร์ชันเก่าที่อยู่ในโฟลเดอร์การตั้งค่าหลักของ NVDA โดยตรง ระบบจะคัดลอกเนื้อหาไปยังโฟลเดอร์ย่อยใหม่โดยอัตโนมัติ และจะลบไฟล์เก่าทิ้งก็ต่อเมื่อตรวจสอบความถูกต้องของการคัดลอกเรียบร้อยแล้วเท่านั้น เพื่อให้แน่ใจว่าการปรับแต่งของคุณจะไม่สูญหายระหว่างการอัปเดต

8. เปิด / ปิด การใช้งานโดยไม่สูญเสียการตั้งค่า


การปิดการทำงานของส่วนเสริม (ด้วยการกด Shift+Backspace สองครั้งติดกัน) จะเป็นเพียงการหยุดตอบสนองต่อปุ่มลัดอักขระเท่านั้น ชุดอักขระที่คุณตั้งค่าไว้จะยังคงถูกบันทึกไว้อย่างปลอดภัยและพร้อมใช้งานทันทีที่คุณเปิดส่วนเสริมกลับมาอีกครั้ง


หมายเหตุ: ปุ่มลัดสำหรับแทรกอักขระ (Ctrl+1–0, Ctrl+-, Ctrl+=) จะใช้งานได้ก็ต่อเมื่อส่วนเสริมเปิดทำงานอยู่เท่านั้น หากกดแล้วไม่มีอะไรเกิดขึ้น ให้ตรวจสอบว่าส่วนเสริมถูกปิดการทำงานด้วยการกด Shift+Backspace สองครั้งติดกันหรือไม่
