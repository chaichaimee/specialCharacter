specialCharacter Authors: 'chai chaimee URL: https://github.com/chaichaimee/specialCharacter Informations specialCharacter is an NVDA add-on designed to assist in typing 26 commonly used special characters in documents such as Word, Excel, and reports. It provides quick access to these frequently used characters, eliminating the need to memorize or look up Alt codes. These characters are often found in official documents, reports, and data tables. 🔑 Hot Keys: Ctrl+0 to Ctrl+9, Ctrl+Minus, and Ctrl+Equals : Define two sets of commonly used special characters — Set 1 and Set 2, each containing 24 characters by default. Users can switch between, rearrange, modify, or add other special characters as they prefer. These options can be accessed under: NVDA menu → Preferences → Settings → Special Characters, allowing customization based on each user’s preferred layout. Shift+Windows+. : – Alt+0150 Em Dash (connecting periods, numbers, or places, e.g., years 2020–2023) Shift+Windows+/ : — Alt+0151 En Dash (used to separate text for elaboration, e.g., He chose the riskiest path — but also the only path to success) Shift+Backspace (1 press): Switches between Set 1 and Set 2 of the commands. Shift+Backspace (2 consecutive presses): Toggles the add-on's functionality on or off. ** All keyboard shortcuts can be reconfigured in Input Gestures.
